本地源码提交：`c73c37bd`；补丁 `0018-feat-expose-department-sharing-in-mobile-web-navigat.patch` 已由现有脚本导出。18 个补丁复现的源码树与开发分支一致，树校验通过。

## 页面关系

此前的临时钉钉登录验证页只负责唤起登录；登录后进入 Seahub 的正常网页。手机网页和电脑网页共用 React 应用、部门空间接口和文件权限，可以在服务端发布前端改动，无需重新安装客户端。

本次调整针对手机浏览器及钉钉内打开的网页，不改变原生 Seafile 客户端的文件列表。

## 调整内容

- 小于 768 像素时，在网页顶部显示“我的资料库、部门共享、共享给我的、更多”。个人资料库入口沿用原有能力判断。
- 部门共享使用电脑网页相同的独立路由和接口。“更多”打开现有侧边导航，保留手工群组等入口。
- 手机侧边导航默认展开资料库分类，支持触摸滚动，并避免继承电脑端折叠为图标的显示方式；补上部门共享所占的导航高度。
- 部门列表和回收站表格增加溢出容器；小屏幕下缩小内边距、允许长名称换行，并为身份和状态预留宽度。
- 部门成员身份改用专用词条“Department member / 部门成员”，避免通用 Member 词条显示为“群组成员”。新增中英文 JavaScript 翻译；后续镜像仍须按现有流程生成静态语言包。
- 入口切换保留上传未完成时的离开确认。
